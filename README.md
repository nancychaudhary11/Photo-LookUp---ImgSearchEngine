# 📸 Photo LookUp

Photo LookUp is a modern and responsive image search web application that lets users discover high-quality images using the **Unsplash API**. Simply enter a keyword, and the application instantly displays beautiful images with the option to load even more results.

## 🌐 Live Demo
🔗https://photolookup.netlify.app/

## ✨ Features

- 🔍 Search images by keyword
- 🖼️ High-quality images fetched from Unsplash API
- 📂 "Show More" button for loading additional images
- ⚡ Fast and responsive search experience
- 🚫 Input validation for empty searches
- ❌ Alerts when no images are found
- 🌈 Modern glassmorphism UI
- 🔗 Click any image to view it on Unsplash
- 📌 Progressive Web App (PWA) support using `manifest.json`


## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- Unsplash API
- Font Awesome


## 📷 How It Works
1. Enter any keyword.
2. Click **Search**.
3. Images are fetched from the Unsplash API.
4. Click any image to view it on Unsplash.
5. Use **Show More** to load additional images.
